## 1. ゲーム概要

漢字をテーマにした**複数のクイズモード**で遊べるゲーム。
遊ぶだけでなく、プレイヤー自身が問題を作り、オンラインに公開して他のプレイヤーに遊んでもらうこともできる。

- ジャンル：教育・学習クイズ
- 想定プレイヤー：漢字を学習・確認したい人、問題を作って共有したい人
- 対象年齢：全年齢。子ども向けに限定はしないが、子どもも遊べるようにする
  - R18 などの不適切な内容に触れないようにする仕組みを用意する（2.4）

### 1.1 ゲームの柱

| 柱 | 内容 |
|---|---|
| 遊ぶ | 複数のゲームモードで漢字クイズを解く |
| 作る | 問題作成モードで、自分でクイズを作る |
| 共有する | 作った問題をオンラインに公開し、他のプレイヤーが作った問題を遊ぶ |

### 1.2 モード一覧

| モード | 概要 | 状況 |
|---|---|---|
| 書き順クイズ | 正しい書き順の図を選択肢から選ぶ | 実装中（3章） |
| 本物の漢字さがし | 偽物の漢字の中から、実在する漢字を当てる | 次に作る（2.1） |
| 返信文クイズ | 状況に合った返信の文を考える | 後回し（2.1） |
| 四字熟語づくり | 漢字を組み合わせて四字熟語を作る | 未着手（2.1） |
| 画像で名前当て | 画像を見て、その名称を漢字で当てる | 未着手（2.1） |
| 問題作成モード | プレイヤーが問題を作る（2.3） | 後回し（フェーズ2） |
| オンライン問題 | 公開された問題を探して遊ぶ（2.4） | 後回し（フェーズ2） |

### 1.3 開発の優先順位

| フェーズ | 内容 | 時期 |
|---|---|---|
| フェーズ1 | ゲームモード5種を遊べる状態にする | 2027年1月の完成目標まで |
| フェーズ2 | 問題作成モード、オンライン共有、アカウント | フェーズ1の完了後 |

## 2. 全体構成（構想）

> この章は今後の構想です。詳細は「8.3 決めること」で詰めます。

### 2.1 ゲームモード（構想）

書き順クイズ以外の4モードの概要。詳細は各モードの実装前に詰める。

**本物の漢字さがし**

- 実在する漢字1つと、それに似せた偽物の漢字を複数並べ、本物を選ぶ。
- 偽物の作り方（部首の入れ替え、画の追加や削除など）は未定。
- 案：KanjiVG の SVG の部品（`kvg:element`）と位置（`kvg:position`）を使い、部品を入れ替えて偽物を自動で作る。6,701 字の部品の組み合わせと照らし合わせて、実在する漢字と同じにならないものだけを使う。表示は書き順クイズの描画を使い回す。
- 決めること：難易度ごとの偽物の違い（部品の入れ替え方、画の追加・削除を入れるか）と、1問の選択肢の数。

**返信文クイズ**

- ある状況やメッセージが示され、それに合った返信の文を複数の候補から1つ選ぶ（選択式）。
- 候補には、漢字の誤りや言葉の使い方の誤りを含む文を混ぜる。
- 2026-10-27：正しい返信文を作る力がまだ足りないため後回しにした。ほかのモードを先に作る。

**四字熟語づくり**

- 提示された漢字を組み合わせて四字熟語を完成させる。
- 漢字の提示方法（ばらばらに並べる、一部を穴埋めにするなど）は未定。

**画像で名前当て**

- 画像を見て、その物の名称（漢字表記）を当てる。
- 例：タンポポの画像 →「蒲公英」
- 回答方法（選択式か入力式か）と、画像の入手方法は未定。

### 2.2 画面遷移（案）

```
タイトル
  └─ メニュー
      ├─ クイズで遊ぶ ─ モード選択 ─ 各クイズモード ─ 結果
      ├─ 問題を作る ─ 問題作成モード ─ 保存 / 公開
      └─ みんなの問題 ─ 問題一覧 ─ プレイ ─ 結果
```

### 2.3 問題作成モード（フェーズ2）

- プレイヤーが出題する漢字や問題形式を選び、問題を作る。
- 作った問題は端末に保存でき、オンラインに公開もできる。
- 作れる問題の形式は、基本的にゲームモードと同じにする。細部は要相談。

### 2.4 オンライン共有（フェーズ2）

- 作った問題をオンラインに公開できる。
- 他のプレイヤーは公開された問題を一覧から探して遊べる。
- サーバーはレンタルサーバーを借りて用意する。
- アカウントは作成できるようにするが、必須にはしない。ゲストでも遊べる。
- 不適切な内容（R18 など）に触れないようにする仕組みを用意する。
- 問題の探し方、評価、通報などの詳細は実装時に決める。

## 3. 書き順クイズモード

漢字の**正しい書き順**を当てるモード。
1問ごとに1つの漢字について、書き順を1画ずつ積み重ねて描いた図が複数並び、その中から正しい書き順のものを1つ選ぶ。

### 3.0 ゲームの流れ

```
ゲーム開始
  └─ 出題リストから問題を作る（作れない漢字は除外）
      └─ 出題（1問目）
          ├─ 選択肢を1つ選ぶ（トグル）
          ├─ [次へ] 押下 → 正誤を記録 → 次の問題へ
          ├─ [前へ] 押下 → 1つ前の問題へ（以前の選択を復元）
          └─ 最終問題で [次へ] → 結果画面へ
```

1. ゲーム開始時に、出題リストのすべての漢字について問題を作る。
2. 作った問題を、出題リストの順に出す。
3. プレイヤーは選択肢を1つ選び、[次へ] を押す。
   - 選択肢を選ぶと「コッ」、[次へ]・[前へ] を押すと紙をめくる音が鳴る。
   - 問題を切り替えると、問題文・漢字・選択肢がスライドして入ってくる（次へは右から、前へは左から、最初の問題は下から）。
   - 前に間違えた漢字（苦手な漢字、3.8）が出たときは、漢字の右に「苦手」のハンコを出す。
4. 何も選んでいない間は [次へ] を押せない。
5. 全問に回答すると結果画面（Result シーン）へ移る。
6. 結果画面では正解数と問題ごとの正誤（○・×）を表示し、[もう一度] で書き順クイズを最初からやり直せる。
   - 結果発表の演出：問題ごとの ○・× を1問ずつ効果音（正解・不正解）つきで出す → 正解数の数字をルーレットのように回す（回っている間はカチカチという音）→ 正解数を「ジャン」という音とともに出す → 級のハンコを押す → 全問正解なら花丸を書く → 自己ベストを出す → ボタンを出す。
   - ○ は朱色、× は青いハンコの画像で、押すように大きいところから縮んで出る。
   - 演出中に画面をクリックすると、残りを飛ばしてすぐに正解数・級・花丸・自己ベストを出す（ジャンの音だけ鳴らす）。
   - 演出中は [もう一度]・[問題を振り返る] を隠し、問題を押しても振り返らない。
   - 振り返りから結果画面に戻ったときは、演出をせずにすぐすべて表示する。
   - 演出の速さ（1問ごとの間隔、ルーレットの長さなど）は `ResultView` の Inspector で調整する。
7. 結果画面の [問題を振り返る] で、問題を振り返れる（3.5）。
8. 結果には級（3.6）と自己ベスト（3.7）を表示する。
9. プレイ中は右上の [メニュー] か Esc で中断メニューを開ける（4.4）。キーボードでも遊べる（4.5）。
10. シーンを切り替えるときは、前の画面がプリントのように上へ回収され、入れ替わりに次の画面のプリントが下から配られる（4.3）。

### 3.1 問題の表示

- 1問につき**選択肢3つ**（`StrokeOrderEntryPoint` の `choiceCount`、2〜4 で変更可）。
- 各選択肢は、書き順を1画ずつ積み上げた図を**横一列**に並べて表示する。
  - 例：5画の漢字なら「1画目まで」「2画目まで」…「5画目まで」の5つの図が並ぶ。
  - 1段階ずつの図を、漢字練習帳のマス目のように黒い四角で囲む。
- 図は1フレームに1段階ずつ描画され、アニメーションのように表示される。
- 選択肢のうち**1つだけ正解**で、正解の位置は問題を作るときにランダムに決まる。
- 残りの選択肢は、正解の書き順を難易度に応じて入れ替えた**不正解**になる。
- 不正解は、**正解とも、ほかの不正解とも重複しない**。
- 描画中に別の問題へ移ると、描画を途中で止める。

### 3.2 難易度

難易度は Inspector の `StrokeOrderEntryPoint` の `difficulty` で設定する。`QuizLaunchOptions.Difficulty` が設定されていれば、そちらを優先する（モード選択画面ができたら、そこで設定する予定）。
テスト用に、F1 キーで画面左下に難易度の切り替えボタンを表示でき、押した難易度で最初からやり直せる（エディタと開発ビルドでだけ使える）。
難易度によって、出題範囲・問題数・不正解の作り方が変わる。

| 難易度（表示名） | 出題範囲 | 問題数 | 出題対象の画数 | 不正解の作り方 |
|---|---|---|---|---|
| Easy（簡単） | 小学漢字 | 5問 | 1画以上 | 全画をランダムに並べ替える |
| Normal（常識） | 常用漢字（小学校で学ぶ漢字を除く） | 7問 | 3画以上 | 連続した画数の30%（最低2画）を、すべて元の位置から動かす |
| Hard（困難） | 常用漢字以外 | 7問 | 5画以上 | 隣り合う2画を1か所だけ入れ替える |

- 「常識」で動かす画の数は、画数×0.3 を四捨五入した数（最低2画）。例：10画→3画、13画→4画、20画→6画。
- 「常識」「困難」は、違いが目立ちすぎないように、離れた画は入れ替えない。

- 出題範囲の詳細は 5.2 を参照。
- 出題する漢字は、出題範囲から毎回ランダムに選ぶ。同じプレイの中で同じ漢字は出ない。
- 画面上部のタイトルと結果画面には「書き順クイズ（簡単）」のように難易度を表示する。

次の漢字は問題を作らずに除外し、出題範囲から別の漢字を選び直す。

- 難易度の画数条件を満たさない漢字
- 重複しない不正解を必要な数だけ作れない漢字（選択肢3つの場合、1〜2画の漢字）
- 書き順データ（SVG）がない漢字

### 3.3 回答と採点

- 回答した直後には正解・不正解を表示しない。正誤は結果画面でまとめて表示する。

- 選択肢はトグルグループで管理し、同時に選べるのは1つだけ。
- チェックボックスだけでなく、行のどこ（書き順の図や余白）をクリックしても、その行を選べる。
- [次へ] を押した時点の選択で正誤を判定し、回答履歴に記録する。
- 回答履歴は問題ごとに「正解・不正解・未回答」の3状態を持つ。
- スコアは回答履歴のうち正解の数とする。

### 3.4 前の問題へ戻る

- [前へ] は1問目では押せない。
- [前へ] を押すと1つ前の問題を表示する。
- 戻った問題では、選択肢の並びは変わらず、以前の選択が復元される。
- 戻った問題で回答を変えて [次へ] を押すと、記録とスコアが上書きされる。

### 3.5 問題の振り返り

- 結果画面の [問題を振り返る] を押すと、最初に間違えた問題（全問正解なら1問目）から振り返りが開く。
- 結果画面の一覧で問題を押しても、その問題の振り返りが開く。
- 正解の行は緑の背景と「正解」、自分が選んだ不正解の行は赤の背景と「あなたの回答」で示す。自分の選択にはチェックが入る。
- 画面上部に「振り返り：正解／不正解」を表示する。
- 振り返りでは選択肢を押せない。[前へ]・[次へ] で問題を切り替え、[結果に戻る] で結果画面に戻る。
- 振り返りから結果画面に戻っても、結果はそのまま残る。[もう一度] を押すと通常の出題に戻る。
- 出題する漢字の右に、**お手本**として正しい書き順で1画ずつ筆で書くアニメーションを表示する（薄い字の上に、線が伸びていくように書く。書き終わったら少し待って繰り返す）。

### 3.6 級

正解率と難易度から「10級〜初段」の級を決め、結果画面でハンコとして押す（`KanjiRank`）。

| 難易度 | 全問正解 | 80% 以上 | 60% 以上 | 40% 以上 | 20% 以上 | 20% 未満 |
|---|---|---|---|---|---|---|
| 簡単 | 5級 | 6級 | 7級 | 8級 | 9級 | 10級 |
| 常識 | 3級 | 4級 | 5級 | 6級 | 7級 | 8級 |
| 困難 | 初段 | 1級 | 2級 | 3級 | 4級 | 5級 |

### 3.7 自己ベスト

- 難易度ごとに、最高の正解数を PlayerPrefs に保存する（キーは `BestRecord_StrokeOrder_Easy` など）。
- 前の記録を超えたら「自己ベスト更新！」を出して音を鳴らす。初めての記録は、1問以上正解していれば更新とする。
- 振り返りから結果画面に戻ったときは保存し直さず、更新の表示はそのまま残す。

### 3.8 苦手な漢字の復習

- 間違えた漢字を「苦手な漢字」として、難易度ごとに PlayerPrefs に保存する（キーは `WeakQuestions_StrokeOrder_Easy` など、改行区切り）。
- 次のプレイでは、苦手な漢字（その難易度の出題範囲にあるもの）を問題数の半分まで優先して出す（簡単は2問、常識・困難は3問）。残りは新しい漢字からランダムに選ぶ。出題順は混ぜる。
- 苦手な漢字に正解したらリストから外す。もう一度間違えたら一番新しくする。
- 覚えておくのは 30 字まで。超えたら古いものから外す。
- 振り返りでは「苦手」のハンコは出さない。

### 4.3 シーンの切り替え

- `SceneLoader` に `SceneTransitionView` を渡すと、演出つきで切り替える（各 EntryPoint で渡している）。
- 前の画面をカメラで1枚描いてプリントにし、少し傾きながら上へ回収する（0.69 秒）。回収している間に次のシーンを読み込む。
- 回収が始まって 0.38 秒たったら（読み込みが遅ければ読み込み後に）、次の画面のプリントが下から少し傾いて配られ（0.69 秒）、机に落ち着くと影が消える（0.19 秒）。2枚の間から机が見える。
- 次の画面のプリントには次のシーンのカメラの映像をそのまま映すので、配られている間も画面は動いている。演出が終わると同じフレームでカメラを画面に戻す。
- プリントが動くたびに紙の音を鳴らす。
- 結果画面は、切り替えが終わってから結果発表を始める。
- カメラの映像に UI を入れるため、各シーンの Canvas は **Screen Space - Camera** にする（Overlay の UI はプリントに映らない）。
- 切り替えの途中はクリックを受け付けず、もう一度切り替えを頼まれても無視する。
- SceneTransition プレハブがないシーンでは、演出なしですぐに切り替える。

### 4.4 中断メニュー

- 右上の [メニュー] ボタンか Esc で開き、もう一度 Esc か [続ける] で閉じる。
- [最初からやり直す] で、今のシーンを読み込み直す（難易度はそのまま）。
- 効果音の音量をつまみで変えられる。すぐに反映し、PlayerPrefs（`Volume_Se`）に保存する。AudioManager が起動したときに読み込む。
- 開いている間は、後ろの画面のキー操作を止める（`InputGate`）。シーンの切り替えの途中は開かない。
- 書き順の線（LineRenderer）より手前に出すため、専用の Canvas（Screen Space - Camera、sortingOrder 20）に置く。カメラは `CanvasCameraBinder` が起動時に設定するので、プレハブを置くだけで使える。
- [やめる]（モード選択・タイトルへ戻る）は、それらの画面ができてから足す。

### 4.5 キーボード操作

| キー | 操作 | 担当 |
|---|---|---|
| 1〜6（テンキーも可） | 選択肢を選ぶ。選択肢の行のチェックボックスの下に番号を出す | `ChoiceListView` |
| Enter / スペース / → | [次へ] | `QuizFrameView` |
| ← | [前へ] | `QuizFrameView` |
| Esc | 中断メニューを開く・閉じる | `PauseMenuView` |
| Enter / スペース | 結果発表の演出を飛ばす | `ResultView` |

- ボタンが表示されていて押せるときだけ反応する。
- 中断メニューを開いている間とシーンの切り替えの途中は、`InputGate` で止める。
- EventSystem（InputSystemUIInputModule）の決定・移動・キャンセルの操作は外している。各 View が自分でキーを受け取るので、二重に反応しないようにするため。

### 4.6 シーンのひな形（新しいモードのシーンの作り方）

1. File > New Scene で「漢字クイズのモード」テンプレート（`Scenes/Templates/QuizScene.scenetemplate`）を選ぶ。
2. 共通の部品がそろったシーンができる：カメラ、EventSystem（決定・移動・キャンセルを外したもの）、AudioManager、SceneTransition、PauseMenu、Canvas（Screen Space - Camera）の下に Background・QuizFrame・ModeContent・ReviewPanel。
3. ModeContent の下にモードごとの UI を置き、GameManager にモードの EntryPoint を付ける。
4. QuizFrame の transitionTargets に、問題を切り替えるときにスライドさせるものを設定する。
5. `Data/Modes/` にモードの定義（Create > KanjiQuiz > モードの定義）を作り、`ModeCatalog` に加える。シーンを Build Profiles に登録する。

- 共通の部品はプレハブのままなので、プレハブを直せば全モードに反映される。
- テンプレートの元のシーンは `Scenes/Templates/QuizTemplate.unity`。共通の部品を増やしたら、こちらも直す。

## 5. 漢字データ

### 5.1 データソース

- [KanjiVG](https://kanjivg.tagaini.net/) の SVG ファイルを使用する。
- 配置場所：`Assets/StreamingAssets/KanjiVG/`（ビルド版でも読める）
- 基本の字形のファイル（6,701 ファイル）だけを置く。楷書体などの異体字のファイルは使わないので含めない。
- ファイル名：Unicode のコードポイントを5桁の小文字16進数にしたもの。
  - 例：「漢」(U+6F22) → `06f22.svg`
- ライセンス：Creative Commons 表示-継承 3.0（CC BY-SA 3.0）。
  - **リリース時にクレジット表記が必要。**

### 5.2 出題リスト

出題範囲は、難易度ごとの漢字セット（JSON）で決める。置き場所は `Assets/TechC/KanjiQuiz/Data/KanjiSets/`。

| ファイル | 難易度 | 内容 | 字数 |
|---|---|---|---|
| `KanjiSet_Elementary.json` | 簡単 | 小学校で学ぶ漢字（2020年度からの学年別漢字配当表） | 1,026 |
| `KanjiSet_Joyo.json` | 常識 | 常用漢字のうち、小学校では学ばない漢字 | 1,109 |
| `KanjiSet_Hyogai.json` | 困難 | 常用漢字以外のうち、人名用漢字と、新聞での使用頻度の順位がある漢字 | 770 |

- 漢字セットは、漢字辞書データ [KANJIDIC2](https://www.edrdg.org/kanjidic/)（EDRDG、CC BY-SA 4.0）の学年情報から `Tools/generate_kanji_sets.py` で作る。
- どのセットも、KanjiVG に書き順データがある漢字だけを入れる。
- 「困難」には、常用漢字の旧字体にあたる人名用漢字（例：顯・眞）は入れない。常用漢字と見分けにくいため。
- 「𠮟」（常用漢字）は、フォント（Klee One）に字形がなく出題する漢字を表示できないため、出題範囲から外している。
- JSON の形式：`{ "id": "Elementary", "title": "小学漢字", "source": "…", "kanji": "愛悪圧…" }`（kanji は漢字をつなげた1つの文字列）

### 5.3 書き順データの読み込み

1. 漢字からファイル名を作り、UnityWebRequest で SVG を読み込む。ファイルがなければその漢字を除外する。
2. `id` が `-s数字` で終わる `path` 要素を1画として、出現順に取り出す。この順番が正しい書き順になる。
3. 各画の `d` 属性（パスデータ）を解析し、座標の列に変換する。解析は問題を作るときに1回だけ行う。
   - 対応コマンド：M, L, H, V, C, S, Z（大文字・小文字とも）
   - 曲線（C, S）は1区間あたり30分割で近似する。
4. 座標は 109×109 の SVG 座標系を中心原点に変換し、3倍に拡大する。

## 6. 描画仕様

| 項目 | 既定値 | 設定場所 |
|---|---|---|
| 線の太さ | 0.15 | CumulativeStrokeRenderer |
| 線の色 | 黒 | CumulativeStrokeRenderer |
| 図と図の横の間隔 | 2.5 | CumulativeStrokeRenderer |
| 角・端の丸め頂点数 | 10 | CumulativeStrokeRenderer |
| 枠（1段階ごとの四角）の表示 | する | CumulativeStrokeRenderer の drawFrame |
| 枠の1辺の長さ | 3（KanjiVG の文字の範囲と同じ） | CumulativeStrokeRenderer の frameSize |
| 枠の線の太さ・色 | 0.4・黒 | CumulativeStrokeRenderer の frameWidth・frameColor |
| シェーダー | Sprites/Default | コード固定 |

- 1画は LineRenderer（KanjiLineRenderer プレハブ）1本で描く。
- 新しい問題を表示するときは、前の描画をすべて削除してから描き直す。
- 画数が多くて図を縮めるときは、画の線も同じ割合で細くする。枠の線はもともと細いので太さを変えない。
- 画は枠より手前に描く（画の描画順は枠より1つ大きい）。

### 8.2 既知の不具合

PR #1 のコードレビューで見つかった不具合は、書き順クイズの MVP 化ですべて解消した。

| 内容 | 対応 |
|---|---|
| SVG の読み込み先がエディタ専用のフォルダで、ビルド版では読めない | StreamingAssets へ移し、UnityWebRequest で読む |
| 不正解の選択肢が正解と同じ書き順になることがある | 重複しない不正解だけを作り、作れない漢字は除外する |
| 描画中に問題を切り替えると、前の漢字の図が混ざる | 問題を切り替えると描画をキャンセルする |
| SVG がない漢字を出題すると例外で止まる | その漢字を除外する |
| [前へ] で戻る先がスキップ対象だと元の問題に戻る | 問題は最初にまとめて作るので、スキップが起きない |
| 残りの問題がすべてスキップ対象だと前の問題が残る | 同上 |
| 前の問題に戻ったとき、以前の回答が表示されない | 以前の選択を復元する |
| SVG を Unity の SVG インポーターが読み込もうとして全件失敗する | StreamingAssets はインポートされないので解消 |

現在わかっている不具合はない。
